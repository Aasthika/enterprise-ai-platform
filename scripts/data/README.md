# Data scripts directory

This directory is reserved for reusable scripts related to dataset inspection, validation, cleaning, profiling, and future ETL work.

The current milestone only creates the directory structure and documentation. No implementation scripts are included yet.

## Planned responsibilities

- dataset inspection
- validation checks
- schema review
- cleaning utilities
- profiling and summary reporting
- future ETL pipeline support

## Rules

- keep scripts modular and reusable
- avoid writing to raw datasets directly
- create new outputs for transformed data
- keep credentials and secrets out of the repository

## Out-of-scope for this project phase

The roadmap explicitly does not include:

- Docker-based deployment
- Kubernetes orchestration
- large-scale cloud migration
- multi-region readiness
- LLM fine-tuning
- enterprise-scale distributed systems

The roadmap is intentionally staged to keep the project realistic, modular, and achievable within a local development context.
